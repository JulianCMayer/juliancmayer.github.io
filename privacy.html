Datenschutzerklärung

1. Verantwortlich

Julian Mayer, E-Mail: julian.c.mayer@gmail.com

2. Wie die App arbeitet

NachhilfeManager läuft ausschließlich auf dem Computer der Nutzerin bzw. des Nutzers. Es gibt keinen Server des Anbieters: Weder der Anbieter noch Dritte erhalten Daten aus der App. Die App ist nur auf dem eigenen Computer erreichbar (localhost).

3. Welche Google-Daten die App verwendet

Nach der Anmeldung mit Google und der Zustimmung der Nutzerin bzw. des Nutzers liest die App mit der Berechtigung https://www.googleapis.com/auth/calendar.readonly:

  • die Liste der Kalender (Name), damit ein Kalender ausgewählt werden kann,
  • die Termine eines gewählten Zeitraums (Titel, Beginn, Ende, Ort, Link zum Termin),
  • die Adresse des Hauptkalenders (die E-Mail-Adresse des Kontos), um das verbundene Konto anzuzeigen.

Die App liest nur. Sie erstellt, ändert oder löscht keine Termine.

4. Wofür die Daten genutzt werden

Aus Terminen, deren Titel einen Doppelpunkt enthält („Gruppe: Schüler“), legt die App auf dem eigenen Computer Nachhilfetermine, Gruppen und Schülerinnen und Schüler an und berechnet deren Preise. Andere Termine werden nur angezeigt, solange die Seite geöffnet ist, und nicht gespeichert. Die Daten werden für nichts anderes verwendet: keine Werbung, kein Verkauf, keine Weitergabe, kein Training von KI-Modellen.

5. Speicherung und Sicherheit

  • Die übernommenen Termine, Gruppen und Schüler liegen in einer Datenbank auf dem eigenen Computer.
  • Die Google-Anmeldung wird als Zugriffsschlüssel (Refresh-Token) gespeichert, verschlüsselt: unter Windows mit der Windows-Datenschutz-API (nur für den angemeldeten Windows-Benutzer lesbar), unter Linux im Schlüsselbund des Systems bzw. in einer nur für den Benutzer lesbaren Datei. Passwörter speichert die App nie.
  • Die Verbindung zu Google erfolgt verschlüsselt (HTTPS).

6. Weitergabe

Google-Daten werden an niemanden weitergegeben. Sie verlassen den Computer der Nutzerin bzw. des Nutzers nicht.

7. Löschen und Widerruf

  • „Trennen“ in der App widerruft den Zugriff bei Google und löscht den gespeicherten Zugriffsschlüssel.
  • Der Zugriff kann jederzeit auch unter myaccount.google.com/permissions entzogen werden.
  • Einzelne Termine, Gruppen und Schüler lassen sich in der App löschen; die Deinstallation mit „Daten löschen“ entfernt alle Daten vom Computer.

8. Google API Services User Data Policy

Die Nutzung und Übertragung von Informationen, die NachhilfeManager von Google-APIs erhält, an andere Apps entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung („Limited Use“).

Privacy Policy

1. Responsible

Julian Mayer, e-mail: julian.c.mayer@gmail.com

2. How the app works

NachhilfeManager runs only on the user's own computer. There is no server of the developer: neither the developer nor any third party receives data from the app. The app can only be reached on the user's own computer (localhost).

3. Which Google user data the app accesses

After the user signs in with Google and gives consent, the app reads, with the scope https://www.googleapis.com/auth/calendar.readonly:

  • the list of calendars (names), so that the user can choose a calendar,
  • the events of a chosen period (title, start, end, location, link to the event),
  • the ID of the primary calendar (the account's e-mail address), to show which account is connected.

The app only reads. It never creates, changes or deletes calendar events.

4. How the data is used

From events whose title contains a colon ("Group: Students") the app creates tutoring sessions, groups and students on the user's computer and calculates their prices. Other events are only shown while the page is open and are not stored. The data is used for nothing else: no advertising, no selling, no transfer to others, and no training of AI or machine-learning models.

5. Storage and security

  • Sessions, groups and students taken over are stored in a database on the user's computer.
  • The Google sign-in is kept as a refresh token, encrypted: on Windows with the Windows Data Protection API (readable only by the signed-in Windows user), on Linux in the system keyring or in a file readable only by the user. The app never stores passwords.
  • All connections to Google use HTTPS.

6. Sharing

Google user data is not shared with anyone. It does not leave the user's computer.

7. Deletion and revoking access

  • "Trennen" (disconnect) in the app revokes the access at Google and deletes the stored refresh token.
  • Access can also be removed at any time at myaccount.google.com/permissions.
  • Single sessions, groups and students can be deleted in the app; uninstalling with "delete data" removes all data from the computer.

8. Google API Services User Data Policy

NachhilfeManager's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
